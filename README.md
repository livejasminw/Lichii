# P.T. PC Port for iPhone Duo

CI build of LoreanXavier/pt-pc (MIT, https://github.com/LoreanXavier/pt-pc) for iOS, with
iPhone Duo changes in `patches/*.diff`. No game data here: the app reads chunk1.psarc,
texture.qar and pathid_list_ps4.bin from your own copy, placed in the app's Documents folder.
